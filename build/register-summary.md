# Utility Building Blocks

General purpose patterns for reuse


Things that are common, but not scoped OGC.  Labelling - such as different forms of multi-part and multilingual labels


## Building Blocks

### `ogc.bbr.utils.compoundName.ontology` — Compound Name Model

**Type:** model

Ontology and SHACL rules for compound names: names made of typed name parts, with rules for how the parts relate to the formatted name.

### `ogc.bbr.utils.compoundName.schema` — Compound Name

**Type:** schema

A multiple part name, consisting of a set of strings with functional roles that can be combined into single string using a template.
